# Pedidos

Painel local de pedidos com WhatsApp Web.

## Como baixar e usar
Baixe o ZIP em Code > Download ZIP, extraia, instale Python e execute `python -m pip install -r requirements.txt` e `python main.py`.

A mensagem é aberta para revisão e envio manual; estar pronto não significa que o cliente foi notificado. O banco SQLite e a sessão do WhatsApp são locais. Não publique dados de clientes e faça backup antes de excluir pedidos concluídos.
